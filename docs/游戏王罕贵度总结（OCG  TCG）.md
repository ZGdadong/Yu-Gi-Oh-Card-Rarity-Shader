## 6. 快速识别方法

### 看卡名
- 银色卡名：R
- 金色卡名：UR
- 红色卡名：20th SER / 红碎
- 白色碎闪卡名：PSER / 白碎

### 看卡图
- 只闪卡图、卡名不闪：SR
- 卡图闪 + 卡名金：UR
- 斜向碎冰闪膜：SER
- 卡图浮雕凹凸：UTR
- 银白幽灵立体：HR / Ghost Rare
- 彩虹反射边框：CR

### 动手摸
- 卡图有明显凹凸浮雕感：UTR

### 看闪膜
- 平卡基底 + 全息闪膜：NPR / 平爆
- 有“KC”标志：KC 闪
- 有埃及文字：千年闪
- 全卡面平行闪膜：PSER / Starlight Rare
- 整卡平行全息：Starlight Rare

### 看官方标注
- 卡牌右下角编号旁的字母代码，如 N、R、SR、UR、SER、UTR、HR、CR、PSER 等，是最准确依据。

## 7. 注意事项

1. 同一张卡可能复刻为多种罕贵度。  
2. 罕贵度本身不等于价格，价格还受发行量、环境强度、品相、语言、版本影响。  
3. 地区简称不同：OCG 的 HR 对应 TCG 的 Ghost Rare。  
4. 再版、礼盒、预组、比赛包、特典包中的罕贵规则可能不同。  
5. 玩家俗称容易混淆，例如“金闪”“爆闪”“碎闪”“白碎”“红碎”“星闪”等。  
6. 最准确判断方式：官方数据库 + 卡牌编号旁字母 + 实卡闪膜 / 工艺。
