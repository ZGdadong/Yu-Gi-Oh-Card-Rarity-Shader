语言代码说明（BCP 47）
======================

本目录下的语言包文件名就是**语言代码**，用的是 BCP 47 语言标签，格式：

    语言-地区        例如 zh-CN / en-US / ja-JP

  · 前半段是语言（ISO 639-1 两字母；没有两字母代码时用 ISO 639-3 三字母）
  · 后半段是地区（ISO 3166-1 alpha-2 两字母，大写）
  · 中间用连字符，**大小写敏感约定**：语言小写、地区大写

为什么不用简单的 "zh" / "en"：
  同一个语言在不同地区会是不同的卡牌术语。游戏王的卡名与罕贵度叫法在
  日本（OCG）／北美（TCG）／亚洲英文版之间并不一致，地区段留出位置，
  以后要加 zh-TW（繁体）或 en-GB 也不用改结构。


现有的语言
----------

  zh-CN   中文（中国大陆）      —— 默认语言，也是缺键时的兜底
  en-US   English (United States)
  ja-JP   日本語（日本）


加一种语言
----------

  1. 复制 zh-CN.js，改名成目标语言代码，例如 ko-KR.js
  2. 改文件里的 code / name，把 texts 的**值**翻过去
     ⚠️ 键（texts 的 key）一个都不要动，也不要排序 ——
        tools/doc-check.mjs 会检查各语言包的键集合与 zh-CN 是否完全一致
  3. 在 languages.js 的清单里加一行：{ code: 'ko-KR', name: '한국어' }
  4. 刷新页面，右上角语言下拉框里就有了

  ⚠️ 语言包是 **.js 不是 .json**：`fetch('./Languages/xx.json')` 在 `file://`
     下会被 CORS 拦掉（每个本地文件是独立来源），而这个项目要求双击 index.html
     就能跑。所以语言包写成一句 `CardI18nPack['xx'] = { ... }`，用 <script> 加载。


文案里的两种特殊写法
--------------------

  **这样的是粗体**        —— 界面里会渲染成 <b>，翻译时原样保留
  `这样的是着色器名`      —— 例如 `holo`、`name`、`parallel`，**绝对不要翻译**

  {name} {n} {code}       —— 占位符，CardI18n.t(key, {name:'x'}) 会替换，原样保留


缺键会怎样
----------

  当前语言没有这个键 → 回退到 zh-CN → 再没有就回退到代码里写的中文原文
  （js/rarities.js 与 js/config.js 里的文案一直留着当最后一道保险）
  → 最后才显示键名本身。所以漏翻译一两条不会让界面变成满屏 key。
